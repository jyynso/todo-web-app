## ToDo App

### Prerequisites

* .NET 8.0 SDK
* Node.js

### Backend  (ASP.NET Core 8)
```bash
# Go to the API project folder
cd TodoAPI

# Run the  server
dotnet run --launch-profile https 
```

### Frontend
```
# Open another termninal and go to frontend folder
cd frontend

# install dependencies
npm install

# Run the server
npm run dev
```
